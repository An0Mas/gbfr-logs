## 日本語

# Release 1.8.2 - An0Mas fork

> 注意: これは `false-spring/gbfr-logs` の非公式forkです。upstream 版と同じサポートや安定性は保証されません。

## Release Notes

このリリースは、An0Mas fork を upstream 版の `GBFR Logs` と並存できる別アプリとして配布するためのリリースです。

以前の An0Mas `1.8.1` リリースは updater bootstrap 目的のビルドでしたが、アプリ名や識別子は upstream 版に近いままでした。`1.8.2` ではアプリ名を `GBFR Logs An0Mas`、識別子を `com.an0mas.gbfr-logs` に分離し、upstream 版とは別にインストールできるようにしています。

## Highlights

- アプリ名を `GBFR Logs An0Mas` に変更しました。
- bundle identifier を `com.an0mas.gbfr-logs` に変更しました。
- An0Mas版のDBを An0Mas 専用の AppData パスに保存するようにしました。
- `Settings > Data Migration` から既存の `GBFR Logs` データを明示的にインポートできるようにしました。
- 設定JSONのエクスポート / インポートを追加しました。
- updater の参照先を An0Mas fork に維持しています。
- version同期、`update.json`、GitHub Release assets、updater zip、signature の整合性チェックを追加しました。
- READMEを An0Mas fork 向けに更新し、日本語版をメイン、英語版を `README.en.md` として分離しました。

## Data Migration

このリリースは upstream 版のDBを直接共有したり、上書きしたりしません。

データを移したい場合は、`Settings > Data Migration` から明示的にインポートしてください。

- 検出された upstream 版の `logs.db` をインポートできます。
- 任意の `logs.db` を手動選択してインポートできます。
- upstream 版の WebView localStorage にあるメーター設定を、可能な範囲でインポートできます。
- 設定JSONのエクスポート / インポートができます。

既存の An0Mas版データがある場合、DBインポート前にバックアップが作成されます。

## How to Download

- 下の assets から `.msi` インストーラーをダウンロードして実行してください。
- `.zip` と `.sig` は updater 検証用のファイルです。通常の手動インストールでは `.msi` を使ってください。
- An0Mas `1.8.1` bootstrap build をインストール済みの場合、アプリ識別子が変わっているため、この `1.8.2` の `.msi` を手動インストールすることを推奨します。

## English

# Release 1.8.2 - An0Mas fork

> Notice: This is an unofficial fork of `false-spring/gbfr-logs`. Upstream support and stability are not guaranteed.

## Release Notes

This release makes the An0Mas fork install side-by-side with the upstream `GBFR Logs` app.

The previous An0Mas `1.8.1` release was an updater bootstrap build, but it still used app identity close to the upstream build. `1.8.2` changes the app name to `GBFR Logs An0Mas` and the identifier to `com.an0mas.gbfr-logs`, so it can be installed separately from upstream.

## Highlights

- Renames the app to `GBFR Logs An0Mas`.
- Changes the bundle identifier to `com.an0mas.gbfr-logs`.
- Stores the An0Mas database under the An0Mas-specific AppData path.
- Adds `Settings > Data Migration` tools for importing existing `GBFR Logs` data explicitly.
- Adds settings JSON export/import support.
- Keeps updater configuration pointed at the An0Mas fork.
- Adds release safety checks for version sync, `update.json`, GitHub Release assets, updater zip, and signature matching.
- Updates README for the An0Mas fork, with Japanese as the main README and English in `README.en.md`.

## Data Migration

This release does not directly share or overwrite the upstream database.

Use `Settings > Data Migration` to import data explicitly:

- Import the detected upstream `logs.db`.
- Import a selected `logs.db` manually.
- Import meter settings from upstream WebView localStorage when available.
- Export or import settings JSON.

Existing An0Mas data is backed up before replacement during DB import.

## How to Download

- Download the `.msi` installer from the assets below and run it.
- The `.zip` and `.sig` files are updater verification assets. Use the `.msi` for normal manual installs.
- If you installed the An0Mas `1.8.1` bootstrap build, a manual install of this `1.8.2` build is recommended because the app identity changed.
